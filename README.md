# AI 定向营销助手（初稿）

面向跨境卖家的店主、销售、运营：选中一批独立站客户后，**为每个人生成一份不一样的推广邮件**（英语或西班牙语 + 中文对照），审核后模拟发送。

今晚这份初稿可以离线演示，不需要 API Key。

## 启动

```bash
pnpm install
node fixtures/demo-pet/generate.mjs   # 已提交生成结果，通常不用再跑
pnpm seed
pnpm dev
```

- 前端：http://localhost:5173
- 后端：http://localhost:3000
- 账号：`demo@example.com` / `demo1234`

演示里的“今天”固定为 `2026-11-01`。如需覆盖，在 `.env` 里写 `APP_NOW=2026-11-01`。

## 两小时演示路径

1. 登录。
2. 打开「客户」，筛西班牙语，点开 Anna 或 Diego，看档案和备注；可以再加一条备注。
3. 打开「挑选客户」，选「沉睡召回」，确认人数。
4. 意图填「黑五老客专享 8 折，主推猫砂和猫粮」，点「开始生成」。
5. 在审核页看每人一份文案：西语客户是西班牙语，英语客户是英语，都有中文对照。
6. 删掉某份里的 `{{unsubscribe_url}}` 再点通过，应该被拒绝。
7. 恢复后「一键通过」，再「模拟发送」。
8. 点「复制」，粘贴出来是已经填好名字的邮件。

未同意营销的客户不会生成草稿，也不会被发送。
