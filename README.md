# AI 定向营销助手（初稿）

面向跨境卖家的店主、销售、运营：选中一批独立站客户后，**为每个人生成一份不一样的推广邮件**（英语或西班牙语 + 中文对照），审核后模拟发送。

今晚这份初稿可以离线演示，不需要 API Key。

## 启动

```bash
pnpm install
# 如果 seed 报 better-sqlite3 找不到 .node，在仓库根目录执行：
# pnpm rebuild better-sqlite3
node fixtures/demo-pet/generate.mjs   # 已提交生成结果，通常不用再跑
pnpm seed
pnpm dev
```

- 前端：http://localhost:5173
- 后端：http://localhost:3000
- 账号：`demo@example.com` / `demo1234`

演示里的“今天”固定为 `2026-11-01`。程序不会读取 `.env`。要改日期，启动后端时带上环境变量，例如 `APP_NOW=2026-11-01 pnpm --filter api dev`。

## 端到端操作清单

打开 http://localhost:5173 。没有单独的营销首页：未登录会进入登录页。人数以下面为准；如果对不上，先停掉服务再执行一次 `pnpm seed`（会清空这家店之前的推广、备注和标签）。

1. 登录页邮箱 `demo@example.com`，密码 `demo1234`，点「登录」。进入客户列表，侧栏店名是「Paws Demo」。
2. 客户列表应显示「共 40 人」。语言选「西班牙语」，应变为 16 人。再选回「全部」。
3. 点开 **Anna Cole**。画像应为英语、US、同意接收邮件，订单里能看到金额（例如 $57.30），备注里有布偶猫 / 无尘猫砂。
4. 偏好标签输入「布偶猫」，点「添加标签」，标签出现在画像里。再试空标签和超过 40 字，应分别提示「标签不能为空」「标签最多 40 个字」。
5. 打开「挑选客户」，场景保持「沉睡召回（60 天以上未购买）」。应看到：共 32 人，可触达 27 人，排除 5 人（未同意营销）。可触达里英语 14 人、西班牙语 13 人。
6. 推广意图保持「黑五老客专享 8 折，主推猫砂和猫粮，强调囤货划算」，折扣码 `SAVE20`，点「开始生成」。按钮会变成「正在为客户生成文案…」，然后进入这份推广的审核页。
7. 审核页标题带「待审核」，黄条写可触达 27、排除 5。左侧约 27 份文案，英语客户是英语，西语客户是西班牙语，每份都有中文对照。点 Anna Cole：中文对照里应有「备注」；若第 4 步的标签是在生成前加上的，还会出现「偏好：布偶猫」。
8. 在正文里删掉 `{{unsubscribe_url}}`。不用保存，「通过」按钮变灰，并提示必须保留该占位符。用撤销把占位符加回去，按钮恢复可点。
9. 点「一键通过」。应提示「已通过 27 份，跳过 0 份」，列表状态变为「已通过」。
10. 点「模拟发送」。应提示「已模拟发送 27 封」，标题状态变为「已发送」。未同意营销的 5 人不会出现在文案列表里，也不会被发送。
11. 仍选中 Anna，点「复制」。页面下方出现填好的最终文案：正文里有 Anna，没有留下 `{{`，折扣码是 SAVE20，并带退订链接和公司地址。若浏览器允许，同时写入剪贴板；若不允许，直接选中页面上的这段文字复制。

生成失败时，「挑选客户」页会显示接口返回的错误，而不是按钮转圈后没有任何提示。
