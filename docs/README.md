## 状态标记约定

文档中使用以下三种标记，避免把建议误当成已决定的事项：

- **已确认**：负责人已经明确的方向。
- **建议（待确认）**：本文档提出的默认方案。负责人没有提出反对时，按此执行。
- **待确认**：会影响实现的关键问题，开工前或对应任务开始前需要回答。
