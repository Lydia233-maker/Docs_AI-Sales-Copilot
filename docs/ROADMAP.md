# 路线图

产品名 **AI定向营销助手**，当前版本 **V0.1**。下一版要做完的范围已确认，见 [TODO.md](./TODO.md) 的「下一版必做」。版本号到发布时再定。

## 已完成

- pnpm monorepo、React 页面、Fastify API、SQLite、共享 Zod 类型。
- 演示账号登录与 Cookie 会话。
- 灌入 40 位宠物用品客户及订单，算出语言、品类、消费层级、距今天数。
- 客户列表与档案；追加备注；添加偏好标签。
- 沉睡召回与全部客户两种挑选；生成前显示可触达与排除人数。
- 每人一封本地模板邮件（英语或西班牙语 + 中文对照）。
- 修改草稿、单份通过、一键通过、阻止缺少退订链接或公司地址的文案。
- 模拟发送，以及在页面上查看填好占位符的正文。
- 单元测试：简报拒绝姓名类字段、占位符白名单、资格判断、模板含标签、缺退订链接被阻止。
- 冒烟脚本覆盖登录到模拟发送。

## 开发中

整理文档时，当前检出分支没有未提交的功能改动。其他分支是否正在开发：待确认。

- 客户搜索参数 `q` 存在，页面没有搜索框。

## 下一版必做

2026-10-11 确认：这些都是下一版的优先级，要在下一版做完。明细和验收口径见 [TODO.md](./TODO.md)。

## 再往后

需求里有、但没有放进下一版的：邮件预览文本、单批 200 人上限、商品 CSV、10 位客户的模型对比。

需求明确不做：Amazon / Temu / SHEIN / Shopee / Lazada / TikTok Shop、WhatsApp 自动发送、短信、自动化流程编排、可视化邮件编辑器、广告投放、对外开放注册和计费、批发文案。
