# 图片说明

这些图只供网页视觉参考，不要把图里的人数写成线上站点的当前人数。线上站点以打开 http://101.37.236.139:3000 后看到的为准。

1. `01-总览-字段怎么算.png`：产品总览下半部分。深绿色侧栏、米色背景、白色卡片。网页应沿用这个配色，不要改成黑底霓虹。
2. `02-挑选客户.png`：挑选客户页。场景、语言、品类、消费层级，以及个性推广的定义。
3. `03-单独写信的样式-本地演示店.png`：一封「单独写」的信长什么样，包括中文对照和 20% off。这是本地 40 人演示店里的 Anna，不是线上那 300 个弃单样例。网页上可以展示这种版式，但不要写成「线上现在有 Anna 这位客户」。
