# Shopify 公开样例

用来核对导入代码，不是演示店数据。邮箱来自样例本身，不要当成真实客户。

| 文件 | 来源 | 说明 |
| --- | --- | --- |
| `customer_template.csv` | [Shopify 客户 CSV 模板](https://help.shopify.com/csv/customer_template.csv)，2026-10-11 下载 | 官网**导入**模板。有姓名、邮箱、邮件营销同意、国家代码、备注。没有 `Customer ID`、`Total Spent`、`Total Orders` |
| `orders_export_sample.csv` | [公开订单样例](https://tryprofitroot.com/samples/sample-shopify-orders-SAMPLE.csv) | 表头与 [Shopify 订单导出说明](https://help.shopify.com/en/manual/fulfillment/managing-orders/exporting-orders) 一致。同一订单的后续商品行把订单号、邮箱等留空。这不是 Shopify 官方文件 |

卖家自己的导出文件仍需在试用前再对一次。
